PARCHE ROLO — VERSION PHP + MYSQL (XAMPP)

CONTENIDO
- index.html, style.css, script.js y las 7 músicas (incluye las dos canciones nuevas que compartiste).
- config.example.php: configuración de conexión. Copiar como config.php.
- db.sql: tablas de administradores, ajustes, eventos de partida, cartas personalizadas y músicas.
- install.php: crea el primer usuario administrador de forma segura (password_hash).
- admin/login.php y admin/index.php: acceso privado, edición de disponibilidad/orden de canciones, altas de cartas y actividad registrada.
- api/event.php: guarda eventos de interacción en MySQL.

INSTALACIÓN LOCAL
1. Instala XAMPP y enciende Apache y MySQL.
2. Copia la carpeta parche_rolo a C:\xampp\htdocs\parche_rolo (Windows) o al directorio htdocs equivalente.
3. Abre http://localhost/phpmyadmin e importa db.sql.
4. Copia config.example.php con el nombre config.php y ajusta host, base, usuario y contraseña según tu MySQL.
5. Abre http://localhost/parche_rolo/install.php y crea tu usuario/contraseña de administrador. Contraseña mínimo 12 caracteres.
6. Elimina install.php después de crear la cuenta.
7. Abre http://localhost/parche_rolo/ para jugar. Panel privado: http://localhost/parche_rolo/admin/login.php

IMPORTANTE SOBRE DATOS Y SEGURIDAD
- No subas config.php ni credenciales a GitHub público. Cambia app_key por una cadena aleatoria larga.
- En un hosting público usa HTTPS, usuario MySQL dedicado con permisos mínimos y una contraseña fuerte.
- Esta versión guarda en MySQL los eventos de interacción enviados al API y las cartas/músicas que administras desde el panel. La lógica original aún mantiene parte de preferencias, favoritos, historial y partida guardada en localStorage del navegador; no significa que absolutamente todos los datos personales estén sincronizados entre dispositivos todavía.
- La app sigue funcionando como juego estático si no está bajo PHP, pero login y API requieren un servidor PHP/MySQL. La selección de canciones guardada por navegador usa localStorage.
- No hay contraseñas ni datos reales preconfigurados. Debes instalar y configurar tu propio servidor.
